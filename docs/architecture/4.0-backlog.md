## Context-aware repeated-exercise performance comparison

Approved requirement, NOT implemented in Configurable Journal.

- Exercise identity remains global by exact exerciseId; full history remains globally
  accessible. Never duplicate ExerciseDefinitions because templates share an exercise.
- If the same exerciseId occurs in more than one active template, default performance
  comparison uses the originating persistent templateId. Compare like-template exposures;
  do not borrow another template's prior exposure as the default benchmark.
- If only one active template contains the exercise, current comparison may remain.
- No prior comparable exposure in that template means insufficient contextual history,
  not a fabricated comparison from another template.
- Global Progress should eventually offer all definition history and optional template
  grouping/filtering.
- Exact exerciseId and persistent templateId only: no exercise/template names, A/B/C/D
  letters, slot indices, hardcoded IDs or fuzzy matching. Template rename preserves context.
