## Boundaries

Template replacement changes the selected slot reference and its definition-derived display fields. Other slots and historical workout snapshots are not renamed. Existing equipment-sensitivity editing remains unchanged: editing sensitivity for the same definition is still a shared-definition setting. A future explicit global rename remains a separate operation.

Unknown replacement references in existing slots preserve the previous slot; newly added exercises still register their explicit new IDs. The editor initializes names from the library, retaining the stored label only for unresolved references. No inference uses that label.

Report candidates use every exercise in the current persisted templates (the model has no separate active flag). Removing a reference removes the candidate unless another current template references it. Equal display names and aliases do not merge different IDs. Missing/unknown canonical references are excluded. No ReportSelectionPolicy is introduced.
