# CoachReport semantic alignment

Scope: Desktop presentation only, following approved ReportSelection. No Analytics/Core semantics, storage, sync, Mobile, production or HumanCoach changes.

## One verdict

Before: ReportSelection ranked full-exposure classification, while CoachReport rescanned workouts and ran Core's legacy `compareExercises` on the latest two grouped occurrences. Its best-set-first verdict could disagree with selection.

After: Tracking → ExerciseExposureHistory → ExerciseProgressClassification → ReportSelection → Desktop `coachReportProgress` → CoachReport. The adapter consumes the existing `selected.progress`; it never reclassifies, groups, or searches history. Ranking, status, reason codes and evidence remain unchanged. Both the visible pill (also PNG) and copied text use the same presentation result.

## Presentation

| Analytics status | Desktop label | Tone |
| --- | --- | --- |
| PROGRESS | Progres | positive |
| REGRESSION | Regres | negative |
| stable FLAT | Bez zmian | neutral |
| FLAT + mixed | Wyniki mieszane | neutral |
| FLAT + trade-off | Kompromis ciężar / powtórzenia | neutral |
| FLAT + changed set count | Zmieniona liczba serii | neutral |
| NOT_COMPARABLE | Brak porównywalności / Inny kontekst sprzętu / Brak kontekstu siłowni | neutral |
| INSUFFICIENT_DATA | Za mało danych / Brak poprzedniej ekspozycji | neutral |

Reason codes only refine labels within a status. Mixed takes precedence over trade-off and set-count labels; the current classifier also marks set-count changes as mixed. No raw enum names, exercise-specific labels or recommendations. All full evidence remains attached to the adapter result.

## Best-set facts

Previous/current best sets and dates/gym labels remain, using Core `getBestSet` on the working sets already present in `comparisonExposure` / `currentExposure`. They never determine tone, ranking or verdict. The previous column now represents the actual classifier-selected comparison exposure, which can be older than the immediately preceding workout. For NOT_COMPARABLE the supplied candidate remains visible as factual context, with an explicitly non-directional status. Missing exposures/complete sets display a dash; no substitute history is inferred.

Layout, notes, charts and export mechanics are unchanged. No new history scan or optimization; existing ReportSelection per-definition scanning remains acknowledged debt.

## Regression coverage

Desktop tests run the real ReportSelection pipeline with generated exercise IDs: every status, mixed/trade-off, both directions of best-set disagreement, missing/different gym, no/single exposure, same-name/alias distinct IDs, the classifier-selected older comparison, unchanged inputs/ranking/evidence and deterministic presentation. A source-wiring regression checks that both visible/copied statuses consume adapter output and legacy comparison/scanning calls are absent from CoachReport.
