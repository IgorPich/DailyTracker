## Upgrade rehearsal status

BLOCKED before installer execution. The host exposes no Windows Sandbox
executable/client, Hyper-V PowerShell tooling, Docker, VirtualBox, or VMware
runner. Optional-feature state could not be queried without administrator
elevation, but no usable disposable environment is currently available. A real
stable 3.0.3 NSIS artifact is present and was only inspected:

- `GreekGod_3.0.3_x64-setup.exe`;
- size: 5,695,359 bytes;
- SHA-256: `F040143048C67B558AB126D4403DACFE2A3873F9860FF38558FB024D254FBEC9`;
- embedded version: 3.0.3.

The required next environment is one of: an enabled disposable Windows Sandbox
with mapped read-only installer inputs and exported results, a disposable VM
snapshot, or another disposable Windows machine. It must not share the current
user's `%APPDATA%`, installation directory, scheduled task, firewall rule, or
Sync Service. Only there may the real 3.0.3 installer, representative copied
data, RC1 upgrade, restart/idempotency, AI-free acceptance, and non-destructive
uninstall inspection be executed.
