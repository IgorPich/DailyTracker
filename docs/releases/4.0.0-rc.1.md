# GreekGod 4.0.0-rc.1

Release Candidate 1 — internal validation build. It is not the final 4.0 release.

## Included in RC1

- schema 8 with safer DailyEntry conflict quarantine and restart-safe sync;
- dynamic Program Builder with any number of templates while preserving the
  existing default program;
- configurable Journal metrics, ordering, tracking periods, and explicit
  `NOT_TRACKED` versus `MISSING_DATA` semantics;
- deterministic Analytics, progress evidence, and report selection;
- structured HumanCoach context and trainer-text ingestion;
- read-only local Companion dialogue, structured memory, and explicit commands
  with preview, confirmation, stale checks, and bounded failure handling;
- managed local-AI lifecycle with checksum-pinned assets and idle shutdown.

AI remains optional. RC1 does not bundle or automatically download a GGUF model,
llama.cpp runtime, Ollama, or any cloud provider. Journal, Training, Program
Builder, Progress, Analytics/Reports, and HumanCoach remain fully usable without
AI assets.

## Upgrade scope

The supported RC rehearsal path is stable GreekGod 3.0.3 to 4.0.0-rc.1 in a
disposable, non-production Windows environment. Existing data is migrated from
schema 7 to schema 8 without changing sync protocol 1 or the application
identifiers. Production installation and user data must not be used for the
rehearsal.

## Not included

This RC does not claim the post-4.0 backlog: contextual repeated-exercise
comparison by template, CoachReport trade-off presentation, automatic
intent-aware DailyEntry merge, cross-template drag/drop, custom Journal metrics,
or final avatar artwork.
