# GreekGod 4.0 private unsigned Windows release policy

Decision date: 2026-09-27. Selected policy: **PRIVATE_UNSIGNED**.

GreekGod 4.0 is a private/limited Windows distribution for the owner and a small
number of known users. The product owner explicitly waives public-trust
Authenticode signing for this release and accepts the associated Windows
`Unknown publisher` and possible SmartScreen warnings. No paid certificate,
cloud-signing subscription, HSM/token or timestamping service is required. This
is an explicit risk/cost decision with a target of 0 PLN, not a technical signing
failure.

## Trust boundary

The Windows binaries are not cryptographically publisher-authenticated. They do
not claim Authenticode integrity, a verified publisher, timestamp protection or
SmartScreen reputation. Users must obtain the installer directly from the owner
or another explicitly trusted distribution path and compare its published
SHA-256 before execution.

SHA-256 is the integrity identifier for the exact distributed installer. It must
be computed from the final 4.0 artifact after every build/packaging change and
verified by the release guard. An older RC installer hash must never be reused.
Because PRIVATE_UNSIGNED has no signing step, there is no post-signing hash stage:
the hash of the exact unsigned distributed file is the final public hash.

All non-signature gates remain mandatory, including the exact artifact surface,
production-authority build, schema/protocol constraints, Windows native-runtime
policy, upgrade validation, AI independence and the immutable 33-file Offline AI
Pack contract.

## Explicit policy states

| Policy | Meaning |
| --- | --- |
| `DEVELOPMENT` | Explicit local development; unsigned artifacts allowed, present invalid signatures rejected. |
| `RC` | Explicit rehearsal/release candidate; intended unsigned behavior retained, present invalid signatures rejected. |
| `PRIVATE_UNSIGNED` | Private/limited release; unsigned GreekGod PEs allowed only by this explicit selection, exact installer SHA-256 and all non-signature release gates required. |
| `PUBLIC_SIGNED` | Public distribution; every required GreekGod PE must have valid SHA-256 Authenticode, exact publisher identity and RFC3161/SHA-256 timestamp. |

There is no default mode and no generic FINAL mode that silently becomes private.
A malformed/tampered existing signature is a failure in every mode; it is never
treated as equivalent to intentionally unsigned.
