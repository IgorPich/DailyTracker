# GreekGod PC 4.0.0 release notes

GreekGod 4.0 is a major local-first Desktop release. Existing 3.0.3 data is
preserved through the schema 7-to-8 upgrade, while workout history remains an
immutable snapshot and exercise identity remains exact and global.

Highlights:

- configurable Journal metrics, ordering, active/inactive state, historical
  tracking periods, and explicit `NOT_TRACKED` versus `MISSING_DATA` semantics;
- Chest and Biceps measurements across Desktop and Mobile synchronization;
- deterministic Analytics, Progress, report selection, and coach context;
- a Dynamic Program Builder supporting any number of templates without changing
  the existing default program;
- local Trainer Text ingestion, structured Companion Memory, coordinated
  reactions, and read-only conversational Companion safety boundaries;
- optional managed local Companion inference through the separately installed,
  qualified offline AI Pack;
- durable DailyEntry conflict quarantine that prevents stale whole-payload
  replay while unrelated synchronization continues;
- improved Windows upgrade UX for the supported stable 3.0.3 path.

Distribution is private and unsigned. Windows may display Unknown Publisher or
SmartScreen warnings. Updates are manual, there is no cloud/Ollama fallback, and
the optional AI Pack is not included in the base installer.

This is a GreekGod PC release only. GreekGod Mobile remains on its independent
release track; future significant Mobile work targets Mobile 2.0.
