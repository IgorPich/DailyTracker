# GreekGod 4.0 clean-Windows native validation kit

Phase 4B prepared the external Windows 10/11 x64 validation that passed on
2026-09-27. Policy B remains unchanged: base Sync Service receives exact app-local
`vcruntime140.dll`; the optional AI runtime receives exact app-local
`msvcp140.dll`, `vcruntime140.dll`, and `vcruntime140_1.dll`; UCRT/API sets remain
OS-provided.

The checked source is `tools/windows-native-validation-kit/`. Its builder accepts
the exact production-authority installer, exact verified 33-file Offline AI Pack,
and a new output directory outside the repository. It refuses an existing output,
an in-repository output, installer hash drift, or a pack that fails the production
verifier. No release binary, model, runtime DLL or generated evidence is tracked.

The portable output contains:

- the pinned installer and Offline AI Pack;
- copies of the authoritative AI/native contracts;
- a read-only preflight with `CLEAN_ENOUGH`,
  `CONTAMINATED_FOR_STRICT_TEST`, and `UNSUITABLE` classifications;
- actual loaded-module checks for Sync Service and managed llama-server;
- manual tracker/inference result recording and a managed-sidecar no-orphan check;
- a sanitized machine-readable evidence collector and concise eleven-step README.

Installed system VC redistributables are recorded but do not cause failure. A
strict pass depends on the loaded modules resolving from the GreekGod application
directory and active managed AI Pack directory with the exact authoritative
versions, sizes and SHA-256 values. System32, WinSxS, PATH and another application
directory cannot pass those checks.

Local assembly, Windows PowerShell 5.1 parsing, exact installer verification,
AI Pack 33/33 verification, read-only preflight execution with isolated AppData,
and synthetic privacy-safe evidence collection passed. No production AppData was
read or modified. The local host was correctly not accepted as strict clean
evidence.

The external physical sequence completed with product-owner-attested
`finalVerdict: PASS`: suitable preflight, real installation, tracker launch, Sync
Service module verification, AI Pack import, real Companion inference, llama
module verification, application shutdown and zero managed llama-server orphans.
The MSVC/UCRT blocker is therefore **CLOSED**.

The copied kit's `evidence` directory is empty; the original generated JSON bundle
was not retained. No evidence files or hashes were recreated. The preserved kit
