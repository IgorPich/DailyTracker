# GreekGod Mobile 2.0 release boundary

Boundary decision date: 2026-09-28.

GreekGod Mobile is a separate release track and is not part of the GreekGod PC
4.0 release gate. Future significant mobile work will be managed under the
GreekGod Mobile 2.0 line and may independently address Android signing and
distribution, mobile-specific UX/features, mobile release/version policy, and
future mobile packaging changes.

This record is only a scope boundary. It does not specify, schedule, qualify, or
start Mobile 2.0, and it does not change the Android package identifier,
version, protocol, schema, sync semantics, or current mobile implementation.
