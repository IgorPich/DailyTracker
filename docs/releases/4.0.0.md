# GreekGod PC 4.0.0

Status: **FINAL ARTIFACT BUILT — EXACT PHYSICAL SMOKE PENDING**

GreekGod PC 4.0.0 is a Desktop-only private Windows release. Distribution is
`PRIVATE_UNSIGNED`, updates are `MANUAL_PRIVATE`, and local AI is an optional,
separately distributed offline AI Pack. The base installer has no model,
llama.cpp runtime, automatic updater, cloud provider, or Ollama fallback.

## Release boundary and limitations

This cut does not release or change GreekGod Mobile. Its application version
remains `4.0.0-rc.1`, Android versionCode remains `3000003`, and future
significant Mobile work belongs to the separate GreekGod Mobile 2.0 track.

Known distribution limitations:

- no public-trust Windows signature; Unknown Publisher/SmartScreen may appear;
- no automatic updater; upgrades are distributed manually and privately;
- the qualified offline AI Pack is distributed separately from the base app.

Runtime data schema remains 8 and Sync protocol remains 1.
